ENGLISH COURSE OVERVIEW
Build a no-Shopify e-commerce storefront with AI-assisted HTML, CSS, and JavaScript; use Google Sheets as a product catalog, Apps Script for order records, WhatsApp for order conversations, and Netlify for hosting. Payments are coordinated through UPI or cash on delivery, not an integrated payment gateway. The example brand Mitti & Wax is a sample business, not the student’s business.

    Is course mein bina Shopify aur bina coding ke apna khud ka e-commerce store banana seekhoge:
   products, cart, checkout aur order seedha WhatsApp par.

Lesson 02 — Store Ka Plan

   Store banane se pehle plan, warna baad mein sab dobara banana padta hai.
  ChatGPT ko ek message mein sab saaf likho: brand, city, products ke naam + price (jo tumne tay kiye),
  customers kaun hain, aur order ka tareeka (cart → Order on WhatsApp).
  ChatGPT se lo: brand ki ek line, categories, website ke saare pages, homepage ke sections upar se
  neeche, aur trust ke liye kya hona chahiye.
   Mitti & Wax categories: Jar, Tin, Pillar, Diya Sets, Gift Boxes.
   Pages: Home, Shop, Product, Cart, About, How to Order/FAQ, Contact, Shipping, Returns, Privacy, Terms.
   Trust: asli photos, saaf price, shipping info, aur asli contact.
  Doosra message: Google Sheet ke liye products ki table. Columns exactly: id, name, category, price,
   description, image, stock.
  Ye table Lesson 4 mein admin panel banegi.

  Galti + fix: Plan mein shipping charge, delivery time ya return policy ChatGPT apne aap tay na kare. Ye
  owner decide karta hai, isliye message mein bolo 'jo detail nahi di woh confirm karne ke liye chhod do'.

Aaj ka kaam

Apne brand ka plan aur products ki table banao.

Lesson 03 — Product Photos + Descriptions

   Usi chat mein 6 product photos aur 2 lifestyle photos ke prompts maango.
  Saare product prompts ek hi style mein: same light, same angle, white background.
  Har prompt ke upar file ka naam: lavender-jar, vanilla-jar, rose-tin, sandalwood-pillar, diya-set, gift-
  box (aur hero, gift wali lifestyle photo).
  Flow → Image mode → Nano Banana. Product photos 1:1, hero banner 16:9 (left side text ke liye khaali
   jagah).
  Download karke sahi naam se images folder mein rakho (mitti-wax/images).
   Descriptions: title, 2–3 lines, bullets aur care instructions (jalti candle ko akela mat chhodo).
   Weight, burn time ya koi aur claim ChatGPT se mat likhwao. Woh owner apne asli product se daalega.

  Galti + fix: File ka naam galat (jaise 'Lavender Jar (1).jpg') hua toh website par photo gayab dikhegi.
 Naam exactly wahi rakho jo table mein hai, chhote akshar mein.

Aaj ka kaam

Saari 8 photos banao aur sahi naam se images folder mein rakho.

Lesson 04 — Google Sheet = Admin Panel

  ChatGPT se final products table tab-separated format mein lo, taaki seedha Sheet mein paste ho.
   Price bina ₹ sign ke, image ka poora path (images/lavender-jar.jpg), aur stock column (abhi sab mein
   10).
  Orders ke liye alag header row: order_id se notes tak. Aur status ke options: New se Delivered tak.

Lesson 05 — Homepage

  ChatGPT ko ek message: homepage ke sections ka order, colours, aur Sheet ka CSV link.
  ChatGPT 3 files deta hai: index.html, style.css, app.js. Har file ka poora code copy karo, beech se kuch
  mat chhodo.
  VS Code → Open Folder → mitti-wax → New file → naam → code paste → Command S.
   app.js mein upar apna WhatsApp number (91 ke baad 10 digits, bina + aur space) aur CSV link daalo.
   index.html ko Chrome mein kholo: hero banner aur neeche products seedha Sheet se.
   Test: Add to Cart → upar cart count badhta hai. Category par click → sirf wahi candles.
  Sheet mein Rose Tin ka stock 0 karo → refresh → site par Sold Out. Code ko haath nahi lagaya.

  Galti + fix: Stock badla par site par turant nahi dikha? Google ka published link 2–5 minute mein
  update hota hai. Thodi der baad refresh karo.

Aaj ka kaam

Apna homepage banao aur Sheet se products live karo.

Lesson 06 — Product Page + Cart

  Message mein dono pages ki har detail: breadcrumb, badi photo, poori description, quantity, aur
  empty cart tak.
   Link aur number ab alag config.js file mein, taaki code update karne par bhi safe rahein.
   Quantity stock se zyada nahi ja sakti, aur cart mein price hamesha Sheet se aata hai (purana price
   nahi chalega).
  6 files: config.js, app.js, index.html, product.html, cart.html, style.css.
   Purani files mein Command A → naya code paste → Command S. product.html aur cart.html nayi files.
  Product par click → badi photo, description, quantity. Stock 0 → Sold Out + neeche baaki candles ke
   suggestions.
   Cart mein har item ka total aur neeche poora order summary. Refresh karne par bhi cart waisa hi rehta
   hai.

  Galti + fix: Koi file aadhi copy hui toh page khaali ya toota dikhega. Har file ka code shuru se end tak
  poora copy karo.

Lesson 07 — Checkout → WhatsApp Order

  Sheet → Extensions → Apps Script → project ka naam → purana code hata ke ChatGPT ka Code.gs
  paste → Command S.
  Deploy → New deployment → Web app → Who has access: Anyone → Deploy.
  Google permission maangega. Ye tumhara apna script hai: Advanced → allow.
  Web app ka link copy karo (ye /exec par khatam hota hai) aur sheet-link.txt mein save karo.
   config.js: CSV link, WhatsApp number aur orders link, teeno quotes ke andar.
   app.js aur style.css poore replace, nayi file checkout.html (aur thank-you.html), baaki pages update.
   Test: cart → checkout form (naam, WhatsApp number, address, city, pincode, payment UPI ya COD,
  notes mein gift message) → Order on WhatsApp.
  WhatsApp mein poora order message Order ID ke saath ready. Website par Thank You page. Sheet
  mein nayi row, status New.

  Galti + fix: Thank You page nahi aaya? Updated code mein WhatsApp naye tab mein khulta hai aur
  order pehle save hota hai. ChatGPT ko batao 'WhatsApp se wapas aane par thank you page nahi dikh
  raha', woh fix de dega.

Aaj ka kaam

Checkout banao, ek practice order bhejo aur Sheet mein check karo.

Lesson 08 — Orders Handle Karna

  ChatGPT se 5 chhote replies: order confirm, UPI, COD, shipped, delivered. Friendly Hinglish mein, har ek
  ke saath shortcut ka naam.
   Koi fake offer nahi. Delivered wale reply mein honest feedback maango, fake review kabhi nahi.
  Normal WhatsApp mein 'Message yourself' wali chat kholo, har reply wahan bhejo aur Star kar do. Ye
  tumhari reply library hai.
  Naya order aaya → Starred messages → confirm reply copy → customer ki chat mein paste aur send.
   UPI wale reply ke saath apna QR bhejo.
  WhatsApp Lists banao: 'Payment Pending', 'Shipped', aur customer ki chat sahi list mein daalo.
  Sheet mein status dropdown se update karo (Paid, Shipped…). Poora record ek jagah.

  Galti + fix: Agar status dropdown mein 'Payment Pending' nahi hai, toh Data validation mein add kar
   lo. List aur Sheet dono mein same naam rakho.

Aaj ka kaam

Paanchon replies save karo aur ek practice order poora handle karo.

Lesson 09 — Baaki Pages + Mobile Check

  4 pages: About, Contact, Shipping, Returns. Har ek mein kya likhna hai saaf batao.
  About mein asli kahani: koi fake award ya fake number nahi.

Lesson 11 — Pehle Customers Laana

  ChatGPT ko store ka link do aur bolo sab honest aur simple likhe: koi fake offer ya fake discount nahi.
   Ek saath lo: 3 Instagram captions (end mein store link), reel ideas (har reel 8 second + screen text),
  WhatsApp Status text, doston/family ko bhejne wala message.
  Flow mein post ki photo: square, cozy, warm light (gift box, cozy corner).
   Instagram: naya post (Flow photo + ChatGPT caption), bio mein store link, har post mein 'link bio mein'.
   Reels: candle jalao, close-up lo, end mein 'link bio mein'.
  WhatsApp Status par daalo: pehle customers aksar apne contacts hi hote hain.
  Doston aur family ko personal message bhejo. Pehla order aksar wahin se aata hai.
  Google Business Profile banao, taaki Google par brand search karte hi dikhe.

  Galti + fix: Ek saath sabko bulk message ya spam mat karo. Har message personal ho, aur zyada se
  zyada ek follow-up.
