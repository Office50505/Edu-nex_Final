Example offline command:

```sh
python3 -B scripts/eval/grade_product_photoshoot_ads_results_v7.py --tests scripts/eval/product_photoshoot_ads_phase10_cases_v7.json --results PATH_TO_SAVED_RESPONSES --scope end_to_end --out NEW_OUTPUT.json
```

This command cannot measure updated live performance. No provider is used by the evaluator. A finite factual-vocabulary/claim check is conservative and still needs independent semantic review. New live validation must freeze this version, independently prepare slot expectations, keep local/repaired/replacement/fallback origins separate and preserve raw outputs. Do not infer readiness from a historical regrade or local replay.
