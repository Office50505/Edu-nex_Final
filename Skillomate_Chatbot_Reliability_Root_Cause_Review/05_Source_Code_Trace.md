`assertKnowledgeScope` (`tutorKnowledge.js:134–143`) validates protected sources/records/debug ownership. `assertCourseTextScope` (`151–158`) is a full known-body defense in depth. `scopeConversationHistory` (`161–166`) filters recognized foreign material; `scopedProviderPayload` checks final messages. Do not replace these checks with an AI instruction or open a global template path to fix reliability.

The six-account/pricing route attribution is source-supported: EG-013 hits plan; EG-017 hits mera+order; SA-001 hits my+paid; SA-019 hits my+paid in a quote; SA-020 hits access; SR-015 hits my name. These are same-user masked summaries or platform offers, not confirmed privacy disclosures.

The full frontend, production app entry point, real database query behavior and external model were not exercised by this review. Pure helper diagnostics establish the identified local mechanisms without pretending to replace end-to-end regression testing.
