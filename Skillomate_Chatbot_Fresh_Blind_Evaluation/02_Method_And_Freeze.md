The runner uses the actual local Express route, JWT compatibility authentication, entitlement logic, course resolution, retrieval, conversation assembly and response implementation. Users, purchases/subscriptions, course documents and session storage are synthetic and memory-only. This validates the application pipeline against controlled dependencies; it does not validate production database contents, billing-provider behavior, production networking or a browser UI. Synthetic public lesson descriptions contain no protected course text. No production database connection is made.

Read-only wrappers capture retrieval returns, context-assembly returns and complete provider payloads before/after the existing scope validator. Wrappers return the original results or rethrow the original errors. They do not select templates, alter course content or supply model answers. Generic harness checks and all harness hashes are preserved. Each executed turn is delivered to the independent grader, which checks ownership and payload content before the next turn may begin. A security alert pauses execution; a confirmed critical failure stops it.

External course-content transmission is not authorized. The configured provider branch may assemble a request, but the network guard rejects all non-loopback transport before transmission. No fake or recorded model response is supplied. Necessary model inference that cannot run is UNTESTED even if a local fallback looks useful. Fully observable deterministic behavior can be graded; a confirmed boundary failure takes precedence over inference unavailability.

The primary denominator remains all 120 planned cases. Cases stopped or dependent on unavailable inference stay in that denominator and are reported separately. Whitespace-only compaction is permitted for approved-body comparisons; Unicode normalization is not. No implementation change, deployment, push, or production operation is part of this evaluation.
