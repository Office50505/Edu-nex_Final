AI FILMMAKING COURSE — CHATBOT TRAINING KNOWLEDGE BASE (Lessons 1–8)
For: Skillomate AI course chatbot · Brand: Skillomate (skillomate.in) Purpose: full detail so the chatbot can answer student questions, give the exact prompts, explain concepts, and troubleshoot — all in simple Hinglish.
0. HOW THE CHATBOT SHOULD BEHAVE
Tone: friendly, simple Hinglish, like a teacher. Short, clear, motivating. No heavy jargon.
Always give copy-paste ready prompts when a student asks “prompt do”.
Tools taught in THIS course = only Google Flow (video), ChatGPT (story/prompts), ElevenLabs (voice), CapCut (editing). Do NOT suggest Seedance/MiniMax/Higgsfield (students don’t have them).
When writing prompts, always write “Reference-to-video” (not “image-to-video”).
Pronounce/write ChatGPT as “chat G.P.T” / “चैट जी.पी.टी” in any spoken/VO line.
Every generation prompt must end with: realism + consistency + anti-glitch + “NO background music, NO soundtrack”.
Course teaches SKILLS (how to get a story, generate shots, cinematography, edit). It is NOT about finishing one single movie — examples are only for teaching.
1. CORE CONCEPTS (chatbot must know these cold)
Google Flow basics
Flow = main video generator (Veo). Max clip ~10 seconds.
Modes: Reference-to-video (attach a reference image → video), Frames (set Start/End frame), Ingredients (attach multiple images + text instructions).
Aspect ratio must be selected in Flow settings (9:16 or 16:9) — writing “16:9” in the prompt alone does NOT change it. If sides look blurred/transparent, the clip was vertical placed in a wide frame → select correct ratio OR force wide composition.
First try rarely perfect → regenerate 2-3 times, pick best take.
Realism formula (so it doesn’t look AI/plastic)
RAW candid iPhone look, real skin with visible pores, natural uneven tone, NOT smoothed, no beauty filter, no waxy skin, natural light. - Do NOT spam “8K / ultra”. Avoid unnecessary slow-motion. - Balance: “pretty but real — no exaggerated pores” (too much realism looks ugly).
Consistency (same face every shot)
Use a locked character reference + write “same face, same outfit” in every prompt.
Start-frame trick: save the last frame of a clip → set it as the Start frame of the next clip → seamless continuation.
Face-fix trick (Frames mode me reference attach nahi hota): use Ingredients mode → attach BOTH (saved last frame + character sheet) → in prompt write: “USE THIS IMAGE [saved last frame] AS THE FIRST FRAME AND TO KEEP THE FACE CONSISTENT THIS IS THE CHARACTER SHEET [reference]. [character desc + location + action]” → frame continues + face stays locked.
Anti-glitch stack (add to prompts)
one person, consistent face, correct anatomy, natural hands with five fingers, everything inside the frame, no morphing, no warping, no flicker, no artifacts, no distortion, no extra limbs. - Too many actions in one clip = glitches → keep ONE simple action per clip.
Flow VIOLATION triggers (avoid — clip gets blocked)
Minor-looking faces → always “clearly adult, mid-20s”.
Revealing/tight/cleavage outfits → “modest, fully clothed”.
Fall / slip / hit / crash / harm / death words → soften or do in edit cut.
Spoken price/financial claims (“₹1”, “24 hours access”) → put as TEXT overlay/end card, not spoken.
Deceptive/AI-disclosure lines (“main AI hoon”, “create a girl like me”) → may be flagged; soften (e.g. “create videos like this”) or move to text.
Presenter / course video format
Presenter = one consistent AI girl (locked face + outfit), speaks FAST continuous Hinglish, no dead gaps, always DOING something (walk/sit/gesture).
Section A & C = white professional studio, 9:16. Section B (practical/screen) = white studio desk + silver MacBook, 16:9 with screen recordings.
Live motion graphics float in synced to her words — style = premium liquid-glass / glassmorphism, icons only, NO text (text glitches in Flow; add text later in CapCut). Added in editing as overlays.
Every clip: NO background music in generation (music added in edit if needed).

Section B — exact ChatGPT prompt (SCREEN REC 1):
Act as an AI film director. Here is my 4-part structure for a SHORT film "[STORY NAME]". I want a 1–2 minute film, so keep it to MAXIMUM 6 shots total — do NOT expand it into many scenes.
Give me the output in this exact order:
PART 1 — CHARACTER SHEET PROMPT (for the character): write ONE image-generation prompt that creates a CHARACTER REFERENCE SHEET — the SAME face shown in multiple angles in one image (front view, 3/4 view, side profile) plus a row of expressions (neutral, sad, crying). Include age, face, hair, skin, and exact clothes. This is a reference sheet, NOT a single normal photo.
PART 2 — SHOT PROMPTS (max 6): ready-to-use Google Flow (Veo) video prompts, shot by shot. RULES: repeat the SAME character description AND the SAME location in EVERY shot so face and place stay consistent. Each shot: camera angle, camera movement, lighting, and the action. Keep it emotional, realistic, and SHORT.
SCREEN REC 2 — Google Flow: character sheet prompt copy → Flow me paste → generate → best reference select (locked).

═══════════════════════════════════════════════ ## LESSON 7 — Camera Movement (8 types) Learn: Flow prompt me camera movement likhो, wo samajh ta hai. 8 movements — kahान kya: | Movement | Prompt word | Kiske liye | |—|—|—| | Slow push-in | “slow push-in” | Emotion, close-up | | Pull-out | “slow pull-out” | Reveal, ending, akelapan | | Handheld | “handheld, strong shake” | Raw, tense, panic | | Static (locked) | “static locked camera” | Stillness, akelapan | | Orbit / arc | “camera orbits around” | Dramatic, hero moment | | Tracking | “tracking shot, follow” | Walking, journey | | Pan | “slow horizontal pan (stays in place, only rotates)” | Left-right reveal | | Tilt | “slow tilt up (stays in place, only rotates, no push-in)” | Height/detail reveal | Rule: ek shot me ek hi movement (warna glitch). Chart = Camera_Movements_Chart.png. Presenter khud har movement self-demo karti hai (b-roll) + bolti “ye hai … movement”. Important: Pan/Tilt me likho “camera stays fixed in ONE position, only rotates, NO push-in” warna Flow push-in kar deta. Handheld weak aaye to “STRONG handheld, visibly shaking, run-and-gun, she walks”.
Q&A: - Shot cinematic kaise? Sahi camera movement daalo (table upar). - Emotion ke liye? slow push-in. Reveal/ending? pull-out. Tense? handheld. Akelapan? static. Dramatic? orbit. Walking? tracking. - Tilt ki jagah push-in aa raha? “camera stays fixed, only rotates vertically, NO push-in, NO zoom” likho.

Q&A: - Emotion ke liye konsा shot? Close-up. Loneliness/jagah? Wide. Normal baat? Medium. Detail/tension? Extreme close-up. Immersive? POV. Do logon ki baat? Over-the-shoulder. - Extreme close-up me chehra badal raha? “EXACT same face as reference, do not change/morph” likho. - POV selfie lag raha? Observer ke haath foreground me daalo + handheld movement + “NOT selfie, she faces the observer”.

4. TROUBLESHOOTING (chatbot quick fixes)
Face har clip me badal raha → reference attach + “same face” + Start-frame trick + Ingredients face-fix.
Bahut glitch (morphing/warping) → ek clip me ek hi simple action rakho + anti-glitch stack add.
Hands/fingers weird → “natural hands with five fingers”.
Clip VIOLATE ho gaya → fall/hit/revealing/death/spoken-price hatao; price/claim ko text overlay pe; “clearly adult, modest”.
Sides blurred/transparent (16:9) → Flow me 16:9 select + “wide horizontal composition, fills entire frame edge to edge, NO blurred side panels”.
Tilt/pan ki jagah push-in → “camera stays fixed in one position, only rotates, NO push-in, NO zoom”.
Handheld too stable → “NOTICEABLE/STRONG handheld, bobs and sways continuously, NOT on tripod, NOT static”.
Text in motion graphics glitching → Flow me text mat generate karao; icons-only (liquid-glass); text CapCut me add karo.
Hindi lip-sync weak → muted generate + ElevenLabs Hindi VO (Devanagari, Speed ~0.9).
